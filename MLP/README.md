## 关键处理方法

### 数据清洗

- **目标变量缺失值用线性插值填补**，而非 `dropna()`。这是时间序列数据，直接删除会造成时间点断裂，导致后续滑动窗口错位。
- `cbwd` 采用独热编码转为数值特征。

### 防数据泄漏（本项目核心）

1. **严禁 `train_test_split`**：时间序列必须按时间轴切分（前 80% 训练 / 后 20% 测试），随机切分会把未来的数据混入训练集。
2. **标准化只能 `fit` 训练集**：用训练集的均值和方差去 `transform` 测试集，测试集必须被视为"未知的未来数据"。
3. **滑动特征必须先 `shift(1)`**：`df['pm2.5'].shift(1).rolling(3).mean()` 严格排除当前时刻的真实标签。

### 特征工程

| 特征 | 构造方式 | 作用 |
| :--- | :--- | :--- |
| `pm2.5_lag_24` | `df['pm2.5'].shift(24)` | 捕捉污染的日周期性 |
| `pm2.5_roll_3` | `df['pm2.5'].shift(1).rolling(3).mean()` | 捕捉短时趋势与累积效应 |

## 模型结构

```
输入层 (12 或 14 维)
  → Dense(64, ReLU) + Dropout
  → Dense(32, ReLU)
  → Dense(1)              # 回归任务，无激活函数
```

- **损失函数**：MSE
- **优化器**：Adam
- **评估指标**：MAE
- **防过拟合**：EarlyStopping + Dropout

## 实验结果

| 模型 | 输入特征 | 测试集 MAE | 测试集 RMSE |
| :--- | :--- | ---: | ---: |
| 基础模型 | 12 维（仅当前时刻） | 48.60 μg/m³ | ≈ 71.1 |
| 优化模型 | 14 维（+ lag_24, roll_3） | **16.68 μg/m³** | ≈ 27.5 |

两者均在约 22 轮触发 Early Stopping。

**结论**：加入时序历史特征后 MAE 下降约 65%。基础模型的 MAE 与直接预测中位数相当，说明它只学到了基础气象特征；引入滞后特征后才真正捕捉到 PM2.5 的历史依赖规律。

训练时 Dropout 处于开启状态，因此验证集 Loss 低于训练集 Loss 属正常现象，不代表异常。

## 已知局限与后续方向

- **长尾低估**：RMSE 明显大于 MAE，说明模型对极端污染事件（PM2.5 > 400）存在低估。
- 下一步可尝试：补充 `lag_1` / `lag_6` / `rolling_24` 等特征；对目标变量做对数变换（`np.log1p` / `np.expm1`）以缓解长尾；超参数调优。
